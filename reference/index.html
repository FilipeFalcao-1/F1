    Settings da aplicação, lidos de variáveis de ambiente com prefixo F1_.

    f1.schemas.endpoints ¶

    Registro declarativo dos 18 endpoints da OpenF1 e da partição do lake.

    Record = dict[str, object] ¶

    EndpointSpec dataclass ¶

    Metadados de um endpoint.

    Attributes:

    Name Type Description

    Nome do endpoint na API (/v1/{name}).

    f1.schemas.silver ¶

    Contratos de dados por endpoint: payload bruto da API e schema tipado da silver.

    raw descreve o que a API entrega (datas como texto; campos polimórficos, como intervals.interval, como texto JSON). silver é o schema gravado em Parquet. Mudanças na API (coluna nova ou ausente) falham o refine do endpoint de forma explícita.

    JSON = pl.String() module-attribute ¶

    Campo polimórfico (número, texto ou lista): mantido como texto JSON até a normalização.

    Contract dataclass ¶

    Contrato de um endpoint.

    Attributes:

    Name Type Description

    Colunas e tipos do payload da API.
    silver Schema

    Colunas e tipos da silver, na ordem gravada.
    optional frozenset[str]

    Colunas que a API pode omitir (somadas aos campos deprecados).

    Extração¶

    f1.extractors.client ¶

    Cliente HTTP da OpenF1 com rate limit, retry e backoff.

    RateLimiter ¶

    Limita requisições por janela deslizante de 1 s e de 60 s.

    A OpenF1 impõe dois limites simultâneos (por segundo e por minuto), então a janela deslizante com o histórico das chamadas é mais simples que dois token buckets.

    acquire() ¶

    Bloqueia até que uma nova requisição caiba nos dois limites.

    OpenF1Client ¶

    Faz GET na OpenF1 e devolve a lista de registros JSON.

    Parameters:

    Name Type Description Default
    http Client

    Cliente httpx já configurado com base_url, timeout e headers.

    		 required
    rate_limiter RateLimiter

    Limitador aplicado antes de cada tentativa.

    		 required
    max_retries int

    Novas tentativas para 429, 5xx, timeout e erro de conexão.

    		 required
    sleep Callable[[float], None]

    Função de espera (injetável para testes).

    		 sleep

    Registros devolvidos. Lista vazia quando a API responde "No results found.".

    Raises:

    Type Description

    Se o 429 persistir depois de todas as tentativas.
    ExtractionError

    Em erro não recuperável ou tentativas esgotadas.

    Transformação¶

    f1.transformers.normalize ¶

    Transformações puras bronze → silver: parse, regras por endpoint e cast para o contrato.

    records_to_frame(records, raw) ¶

    Monta o DataFrame bruto com os tipos do contrato da API.

    Os registros passam por NDJSON porque read_ndjson aceita campos polimórficos (número, texto ou lista) como texto JSON, o que from_dicts não faz.

    Raises:

    Type Description
    DataValidationError

    Se algum valor não couber no tipo declarado.

    normalize(endpoint, frame, contract) ¶

    Converte o DataFrame bruto de um endpoint para o schema da silver.

    Etapas: parse das datas para UTC, regra específica do endpoint (se houver) e cast estrito para contract.silver, que também descarta campos deprecados.

    Raises:

    Type Description
    DataValidationError

    Se algum valor não puder ser convertido.

    split_gap(value, prefix) ¶

    Separa um gap da OpenF1 em segundos e voltas de diferença.

    "+1 LAP"/"+2 LAPS" viram {prefix}_laps_behind (com _seconds nulo); números viram {prefix}_seconds. Texto fora desses formatos falha o cast.

    Parameters:

    Name Type Description Default
    value Expr

    Expressão textual com o valor bruto.

    		 required
    prefix str

    Prefixo das colunas geradas.

    		 required

    f1.transformers.validate ¶

    Validação de contrato e separação de registros válidos e inválidos.

    SplitResult dataclass ¶

    Resultado da separação de uma partição.

    Attributes:

    Name Type Description
    valid DataFrame

    Linhas aptas para a silver, únicas pela chave primária.
    rejected DataFrame

    Linhas para a quarentena, com a coluna reject_reason.
    duplicates_removed int

    Duplicatas exatas descartadas (mesmo conteúdo em todas as colunas).

    check_columns(records, contract) ¶

    Falha se o payload tiver colunas novas ou não tiver colunas obrigatórias.

    Payload vazio é válido (sessões sem dados, como team_radio em 2026).

    Raises:

    Type Description
    DataValidationError

    Em mudança de schema da API.

    split_valid(frame, primary_key) ¶

    Deduplica e separa as linhas que violam a chave primária.

    • Chave com algum valor nulo: rejeitada.
    • Linhas idênticas: mantida uma, sem rejeição.
    • Mesma chave com conteúdo diferente: todas as ocorrências rejeitadas, porque não há como escolher a correta.

    Parameters:

    Name Type Description Default
    frame DataFrame

    Partição já normalizada.

    		 required
    primary_key Sequence[str]

    Colunas da chave primária.

    		 required

    f1.dashboard.charts ¶

    Gráficos Altair do dashboard: funções puras de DataFrame para gráfico.

    As cores seguem a paleta de referência de visualização, validada em ambos os modos: categórica em ordem fixa (no máximo três séries), divergente azul ↔ vermelho com cinza neutro, e compostos de pneu com codificação secundária (letra na barra).

    MAX_SERIES = 3 module-attribute ¶

    Séries com cor própria por gráfico: as três primeiras cores validam todos os pares.

    Palette dataclass ¶

    Cores de um modo (claro ou escuro).

    dark_ink_on instance-attribute ¶

    Compostos cuja letra usa tinta escura (fundo claro, como o amarelo).

    assign_slots(previous, selected) ¶

    Atribui a cada entidade selecionada um slot de cor estável.

    Quem já estava selecionado mantém o slot (a cor segue a entidade, não a posição na lista); quem entra recebe o menor slot livre.

    Parameters:

    Name Type Description Default
    previous Mapping[str, int]

    Atribuição anterior, {entidade: slot}.

    		 required
    selected Sequence[str]

    Entidades selecionadas agora (no máximo MAX_SERIES).

    		 required

    Raises:

    Type Description
    ValueError

    Se houver mais entidades que slots.

    lap_pace_chart(laps, slots, palette) ¶

    team_bar_chart(frame, value, title, palette) ¶

    Barras horizontais de uma medida por equipe (uma série, uma cor), menor primeiro.

    championship_chart(progression, slots, palette) ¶

    Pontos acumulados por corrida: destacados em cor, demais em cinza (ênfase).

    Raises:

    Type Description

    Se nenhum (ou ambos) os filtros forem informados.
    DataValidationError
